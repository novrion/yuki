# Yuki
A personalised AI assistant with a COALA-based memory system.

### Use
Run telegram-bot.py in a Python3 virtual environment. Configure the base personality system instruction in prompts.py and the ai and user names in the intialisation of the Yuki class. Configure llm.py if you want yo use another AI model or provider.

### Requirements
1. Python3 environment
2. Google AI API key
3. Telegram bot and it's ID (created by Telegram's BotFather)
4. Your conversation/user ID with the bot (easily found by outputing the effective user's ID)
5. Local or cloud host (I.e. Google Cloud)
